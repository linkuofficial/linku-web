左右是兩套完全相同的模擬硬體，追同一個目標、吃同一記干擾。左邊跑常見作法（固定增益 PID），右邊把公開的最佳實務正確地部署進同一顆便宜硬體——這就是我們說的：讓整體系統超越同等硬體的一般方案。更快的安定＝更高的節拍；更小的誤差＝更便宜的機構與感測就能達標。

常見作法（真實現狀）　固定增益 PID（Ziegler–Nichols 風格整定）：τ = 9·e + ∫5·e − 1.5·ê̇；速度＝編碼器差分（雜訊直通 D 項），積分僅粗暴限幅（|I| ≤ 0.6·τmax）→ 大步階仍有飽和積分暴衝；階躍指令直接餵，無軌跡、無前饋、無模型
軟硬協同（公開最佳實務的正確部署）　狀態估測（穩態卡爾曼 α–β，ω≈46 rad/s）＋一拍前向預測；近似時間最優速度 governor（PTOS：遠處 v ≤ √(2a·e)、近處線性終端，a ≤ 0.8·τmax/J，留回授餘裕）；模型前饋 τff = J·a_ref + b·ω_ref；動量式擾動觀測器（ω≈12 rad/s）估測並抵消外力矩；回授 τfb = 40·(θref−θ̂) + 11·(ωref−ω̂)（ζ ≈ 0.87）
干擾　點擊＝對兩側同時注入等量衝擊力矩；環境擾動為連續小雜訊力矩（共用序列）
統計　RMS＝最近 4 秒對最終目標的誤差均方根；安定＝事件後首次進入 ±2° 帶並停留 0.3 s 的時間
聲明　右側全部為公開教科書級技術；差距不靠祕密，靠正確的部署與整定——這正是軟硬協同的意義
